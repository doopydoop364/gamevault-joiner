# Installer artwork

Decorative example covers are Steam store artwork for [Hollow Knight](https://store.steampowered.com/app/367520/), [Celeste](https://store.steampowered.com/app/504230/), and [Stardew Valley](https://store.steampowered.com/app/413150/).

The Microsoft, Tux, and Apple marks come from [Font Awesome Free 6.7.2](https://github.com/FortAwesome/Font-Awesome/tree/6.7.2/svgs/brands). The icon files include the [CC BY 4.0 attribution](https://fontawesome.com/license/free).
