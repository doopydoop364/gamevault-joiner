From download to first game

  1. Open Joiner. Check compatibility and follow the prompt to install GameVault. If you already use GameVault 2, open your current client.
  2. Prepare your folders. Use GameVault/Downloads and GameVault/Games in your home folder, or choose your own locations. GameVault 2 uses one library root for both downloading and installing each game. Use Games as the library root and keep any existing roots you use.
  3. Connect in GameVault. Choose New Profile, enter https://gamevault.pcenthusiast.blog, and sign up or sign in. New accounts need administrator approval.
  4. Confirm settings. Follow Joiner’s prompts to check the library root and enable the recommended Downloads and Startup options in GameVault.

Troubleshooting

My computer is outside the supported platforms

Published packages target Windows x64, Linux x64, and Apple Silicon macOS. You can browse the library using the server’s Web UI if available.

The installer is blocked or will not open

Unsigned software can trigger operating system warnings. Follow your device’s security guidance. On Linux, check executable permissions and whether your distribution supports AppImage, or try DEB on a compatible system.

I can’t sign in

Check the full HTTPS address in GameVault. If you just registered, wait for an administrator to activate your account. You can also check whether the server page opens in a browser.

GameVault can’t save or install a game

Check your library root under Settings → Downloads → Download locations. It needs free space and write access. Rerun Joiner’s folder check if you changed the location.
